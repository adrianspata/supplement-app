## Elexir

Personalized supplement and health companion built with React Native, Expo and Supabase.

## Features

- Personalized onboarding and health profiling
- Product recommendations based on goals and health concerns
- Supplement stack management
- Daily insights and progress tracking
- Product comparison tools
- AI-powered health assistant
- Barcode scanning and product search
- Pantry and supplement inventory management

## Tech Stack

- React Native
- Expo Router
- TypeScript
- Supabase
- Open Food Facts API

## Getting Started

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file:

```env
EXPO_PUBLIC_SUPABASE_URL=your_url
EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_key
```

### Start development server

```bash
npx expo start
```
